Hawker Centre Management System

This is a group project that was done as a final assignment to the Back-end Development module in my course. This management system is a website that uses a custom API developed by my team to handle user HTTP requests and database interactions. I had worked with another teammate to set up a large SQL relational database using Microsoft SQL Server Management Studio to create tables and insert sample data. My main features include user authentication, account log in and out and editing account details. All the back-end code was done in JavaScript and utilized Node.js runtime as well as middleware like bcryptjs and jsonwebtoken for password hashing and user authentication.

Multi-Purpose Cloud Solution

This is a group project that was done as a final assignment to the Cloud Architecture and Technology module in my course. The scenario given for this project did not specify any connected features to be developed and hence, each team member had worked on a separate requirement for the assignment. I had implemented a serverless function to post data to a NoSQL database using the tools supplied at Amazon Web Services. Throughout researching and implementing my function, I had done extensive research and documentation on the subject and stayed as true to the AWS Well-Architected Framework as possible.
